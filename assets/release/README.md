# 发布资源

这里保存预览上线使用的压缩资源，原始 PNG/OGG 保留在原目录，方便回退或重新导出。

## 处理规则

- 背景图：按 390px 手机画布的 2 倍宽度导出为 780px JPEG，`yuv420p`，质量参数 `q:v 4`。
- 音乐：导出为 64 kbps MP3，iOS 优先使用 MP3；不支持 MP3 的浏览器回退到原 OGG。
- 音效：导出为 48 kbps MP3，启动阶段不预加载，用户首次操作后按需播放。
- 透明角色帧、装备图标和地图图标仍使用原 PNG，避免透明边缘和像素画细节损失。

## 引用方式

`preview/index.html` 已默认引用本目录中的背景和音频。原始资源不覆盖，发布前可直接替换本目录文件并保持相同文件名。
