# 装备美术资源清单与豆包提示词

## 统一落盘规则

- 生成目录：`cocos-project/assets/resources/art/equipment/`
- 运行时引用目录：`../assets/resources/art/equipment/`
- 文件格式：PNG，512 x 512，透明背景，单件物体居中。
- 物体占画布约 70% - 82%，保留完整轮廓，不裁切，不倾斜到出框。
- 不生成文字、数字、品质边框、UI 底板、徽章、水印和人物手持展示。
- 品质边框由前端根据白、绿、蓝、紫、金、红品质绘制，生成图只负责装备本体。
- 统一风格：暗色国风修仙、旧纸与青铜材质、低饱和青绿与赭金点缀、写实游戏道具图标、高对比轮廓、柔和侧光、轻微磨损、可读剪影。

## 通用提示词

将下面的通用提示词放在每条部位提示词前：

> 国风暗黑修仙解谜游戏装备图标，单件物体，正面略微三分之四视角，透明背景，居中构图，物体占画布 70% 到 82%，写实材质，旧纸、青铜、黑铁、染布与灵光细节，低饱和青绿色和赭金色点缀，边缘清晰，轮廓易读，柔和侧光，轻微磨损但保持完整，高质量游戏 UI 道具图标，512x512 PNG。不要文字，不要数字，不要人物，不要手持，不要场景，不要底板，不要彩色品质边框，不要水印。

## 豆包生成顺序

1. 先生成每个部位的第一张基础资源：武器、法器、护身、头冠、戒指、行履。
2. 再按地图区域补齐变体：药圃、档案区、六灯山道、录痕庭。
3. 生成后只需要把 PNG 放入 `assets/resources/art/equipment/`，文件名保持本清单一致。
4. 预览代码已经保存每件掉落的 `artPath` 元数据；当前没有生成文件时继续使用旧图标占位，不会出现破图。
