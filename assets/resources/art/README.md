# 修仙游戏首批美术资源生成任务单

这份文档可以直接交给豆包执行。目标是为 Cocos Creator 3.8.8 的首个可玩切片 `qi_01 / 灰牌入山` 生成一批原创美术资源。

## 一、生成后放置目录

所有生成好的 PNG 文件直接放入下面的目录，不要新建子文件夹：

```text
C:\Users\hujing\Documents\ChatGPT\修仙\cocos-project\assets\resources\art\
```

文件名必须与本文完全一致，包括英文、下划线和大小写。Cocos Creator 会自动导入这个目录中的资源。

## 二、平台与画布限制

- 游戏平台画布：`390x844`
- 画面方向：竖屏
- 背景建议输出：`1170x2532`，即目标画布 3 倍尺寸
- 人物立绘：`512x768`，透明背景
- 敌人和道具：透明 PNG
- 五行图标：`128x128`，透明 PNG
- 不生成 JPG、WEBP 或带底色的立绘
- 不要把横版海报、横版角色卡或完整 UI 截图当作素材输出

运行时会把素材挂载到固定的 `390x844` 设计分辨率内。横向内容区只有 `358px`，左右各保留 `16px` 安全边距；上下各保留 `18px` 安全边距。素材应保证主体不要贴边，避免在手机画布上被裁切。

## 三、统一画风和版权要求

所有资源使用同一套原创东方修仙游戏美术方向：

- 原创中式修仙世界观，低饱和青灰、墨黑、旧铜、暗红和暖金色
- 2D 手绘概念插画质感，细节清楚，光影克制，适合移动端阅读
- 氛围真实、安静、有悬疑感，不要过度仙侠特效和满屏发光
- 人物脸部、衣服材质、手部和武器结构清晰
- 同一人物的不同表情必须保持脸型、发型、服装、年龄和配色一致
- 这是原创项目，不参考、复制或临摹任何已有小说、影视、动漫、游戏角色
- 不使用已有作品的角色名、门派标志、服饰纹样、法器造型或 Logo

所有素材统一追加以下反向约束：

```text
不要文字，不要汉字，不要 Logo，不要水印，不要边框，不要 UI 按钮，不要对话框，不要游戏界面截图，不要现代物品，不要相机水印，不要多余人物，不要重复肢体，不要畸形手指，不要模糊脸部，不要过度霓虹，不要赛博朋克，不要西式盔甲。
```

## 七、Cocos 挂载规则

代码读取的运行时路径为：

```text
resources/art/<文件名去掉 .png>
```

示例：

```text
assets/resources/art/bg_lanchuan_gate_dawn.png
resources.load('art/bg_lanchuan_gate_dawn', SpriteFrame, ...)
```

不要修改文件名，也不要把文件放入 `assets/resources/chapters`。文件缺失时游戏会继续显示灰盒，不会阻塞剧情测试。
